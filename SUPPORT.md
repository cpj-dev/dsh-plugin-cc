# Support

[English](SUPPORT.md) | [简体中文](SUPPORT.zh-CN.md)

## Where to get help

- Run `/dsh:check` and read [docs/troubleshooting.md](docs/troubleshooting.md) first.
- Use the bug report form for reproducible defects.
- Use the feature request form for scoped enhancements and compatibility proposals.
- Use [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) support channels when the same behavior reproduces outside this plugin.

## Support scope

The project supports the latest released plugin version on the operating systems and Node versions listed in the README. Best-effort help is available for the pinned DeepSeek Harness version. Custom Harness forks, unpinned commits, model output quality, provider outages, and general Claude Code questions are outside the maintained support scope.

When asking for help, include sanitized `/dsh:check` output, the exact command, versions, operating system, run ID, relevant logs, and minimal reproduction steps.

Security vulnerabilities and sensitive logs must follow [SECURITY.md](SECURITY.md), not a public issue.
